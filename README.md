# CircleNote

折叠屏 AI 办公交互演示：AI 结果可直接交互——

- **长按圈选**：长按页面约半秒即可手绘圈选任意段落，圈选印记原样保留（默认褪色，点击恢复）
- **批注浮窗**：圈选完成即在被圈位置旁弹出批注卡片，自动插入输入光标；支持删除、缩小为图标、点击文本重放光标；光标 8 秒无编辑自动消失且全局唯一
- **语音输入**：右下角语音按钮按住 0.3s 后开始识别（轻点不触发）；按住期间流式转写实时显示在当前光标处，无光标时约 2s 后展开下拉对话页并流式显示；扇形指示区在按钮左上方——上拖=插入对话框、左拖=插入批注、左上=取消
- **下拉对话页**：右上角下拉的 9:16 竖向小浮窗，底边拖拽等比缩放，可缩小为图标
- **折叠屏模拟**：折叠 392px / 展开 880px 双栏，批注列表 + 操作记录侧栏

技术栈：React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui；语音识别使用 Web Speech API（Chrome/Edge），无声环境自动切换演示模式。
